## Context

The package skeleton exists: `LyraDs\Blade\BladeServiceProvider` registers `resources/views/components` as the anonymous component namespace `lyra` (Blade::anonymousComponentPath). Pest + Testbench are configured (`vendor/bin/pest`), Pint too (`vendor/bin/pint`).

React contract (verified against packages/react/src/button/button.tsx of the main repo — do NOT deviate; the API source of truth is the React package, never invent API):

Props and defaults:
- `variant`: 'primary' | 'secondary' | 'soft' | 'ghost' | 'danger' — default 'primary'
- `size`: 'sm' | 'md' | 'lg' — default 'md'
- `loading`: bool — default false
- `disabled`: bool — default false
- `full`: bool — default false
- `iconLeft` / `iconRight`: content slots (React ReactNode props → Blade named slots `iconLeft`/`iconRight`)
- label: React `children` → Blade default slot
- React `asChild` is NOT implemented in phase 1 (React-specific Slot mechanism). Document the omission in a code-adjacent place if natural (e.g. a docblock in the view), nothing more.

Class computation (React, cx filters falsy and joins with single spaces):
```
'lyra-btn' + ' lyra-btn--{variant}' + ' lyra-btn--{size}'
  + (loading ? ' lyra-btn--loading' : '')
  + (full ? ' lyra-btn--full' : '')
  + (user classes, ALWAYS LAST)
```

Rendered markup (React reference):
```html
<button class="{cls}" {disabled when disabled||loading} {aria-busy="true" when loading} {...passthrough attrs}>
  {loading: <span class="lyra-btn__spinner" aria-hidden="true"></span>}
  {iconLeft slot content}
  {label present: <span class="lyra-btn__label">{label}</span>}
  {iconRight slot content}
</button>
```
- `disabled` attribute present when `disabled || loading`.
- `aria-busy="true"` present only when loading.
- All other HTML attributes pass through to the root `<button>` (type, form, aria-*, data-*, id...). User-supplied `class` merges AFTER the computed classes.
- The label `<span class="lyra-btn__label">` wraps the default slot only when slot content is non-empty; spinner span appears before iconLeft; order is: spinner, iconLeft, label, iconRight.
